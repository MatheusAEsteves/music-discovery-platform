# 🎵 Nextune
Uma plataforma de descoberta musical desenvolvida com o objetivo de dar visibilidade a artistas independentes e conectar pessoas a novas músicas.

### 📌Sobre o Projeto
O Nextune é uma aplicação web inspirada em plataformas de vídeos curtos e feeds de conteúdo, mas com foco na descoberta musical.

A proposta é permitir que artistas independentes compartilhem pequenos trechos de suas músicas, enquanto os usuários podem explorar um feed personalizado, descobrir novos talentos e conhecer diferentes estilos musicais.

A plataforma busca aproximar artistas e ouvintes, oferecendo um espaço para divulgação de músicas e descoberta de novos sons.

### Funcionalidades
- Cadastro e autenticação de usuários.
- Criação e gerenciamento de perfis de artistas.
- Publicação de trechos de músicas.
- Feed de músicas com navegação contínua.
- Curtidas, comentários e salvamento de publicações.
- Seguir artistas.
- Recomendações personalizadas com base nas preferências musicais.
- Redirecionamento para plataformas como Spotify e YouTube.
- Denúncia de conteúdos e perfis.

As funcionalidades estão sendo desenvolvidas gradualmente.
